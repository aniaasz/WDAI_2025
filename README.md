## 🧪 Labs overview

### Lab 1 & 2 – HTML & Static Website

**Goals (from assignment):**   
- Build simple pages with:  
  - Article layout with heading, author and paragraphs  
  - Product list in an HTML table  
  - Colorful squares using CSS (layout with rows/columns)  
- Final mini‑project: multi‑page **static website** (home, contact, gallery) with:  
  - Semantic HTML, navbar, footer  
  - Layout using Flexbox or CSS Grid  
  - Contact form with inputs, select, textarea  
  - Improved styling, colors, Google Fonts etc.

**Code location:** [lab-01](Lab_01/) [lab-02](Lab_02/)

---

### Lab 3 – JS Arrays, Fetch & Canvas Game

**Goals (from assignment):** 
- Build small browser tools such as:  
  - Stopwatch  
  - Password generator  
  - API data viewer with search and sort  
- Implement a **Flappy Bird** style game using `<canvas>`, animations, collision detection, score handling and localStorage for high scores.

**Code location:** [lab-03](Lab_03/)

---

### Lab 4 – Backend API with Flask & Microservices

**Goals (from assignment):**
- Understand HTTP endpoints, JSON, request bodies, params and JWT. 
- Experiment with API requests using **Postman** or VS Code REST Client.  
- Implement a microservice architecture in Node.js/Express (example domain: book store) with:  
  - Separate services for books, orders and users  
  - ORM (e.g. Sequelize) for database access  
  - JWT‑secured CRUD endpoints and Postman collection.

**Code location:** [lab-04](Lab_04/)

---

### Lab 5 – React + TypeScript

**Goals (from assignment):** 
- Build multiple React components grouped by topic:  
  - Cart and product components  
  - Counters and custom buttons  
  - Forms with live validation and conditional rendering  
  - Student manager with TypeScript interfaces and state  
  - Effects with `useEffect`, timers, `localStorage`, React Router.  
- Practice modern React patterns: props, state, lifting state up, spread operator, hooks (`useState`, `useEffect`).

**Code location:** [lab-05](lab_05/)

---

## 🛠 Tech Stack

- HTML5, CSS3 (Flexbox, Grid, responsive design)  
- Vanilla JavaScript (DOM, `fetch`, canvas)
- Node.js + Express + ORM (microservices – books, orders, users)  
- React + TypeScript (components, hooks, Router)  
- Tools: Git, GitHub, Postman, WebStorm.
